# Kenchua — vermicompost storefront

An image-led marketing site for a vermicompost business, built with Vite,
React and Tailwind CSS v4.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
npm run preview
```

## Pages

| Route          | What it is                                              |
| -------------- | ------------------------------------------------------- |
| `/`            | Parallax hero, stats, product shelf, process, gallery strip, testimonials |
| `/shop`        | Filterable product grid                                  |
| `/shop/:slug`  | Product detail — image switcher, sizes, spec table       |
| `/process`     | The 60-day method, step by step                          |
| `/gallery`     | Masonry gallery with a lightbox                          |
| `/contact`     | Enquiry form and farm details                            |

## Changing the content

Everything — brand, products, prices, process steps, gallery, testimonials —
lives in **`src/data/site.js`**. Nothing else needs editing for day-to-day
changes.

Renaming the business is a one-line change to `brand.name` in that file,
plus the `<title>` in `index.html`.

## Replacing the images

`public/images/*.svg` are placeholders generated by
`scripts/generate-images.mjs` — no stock photos, no external image hosts, so
nothing can 404 on you.

**Drop in your own photographs** by saving them over the files in
`public/images/` (or adding new ones and pointing `src/data/site.js` at
them). Keep roughly the same shape and they slot straight in:

| Use                | Shape        | Files                                     |
| ------------------ | ------------ | ----------------------------------------- |
| Page heroes        | wide, 16:10  | `hero-field`, `field-wide`, `beds-1`      |
| Product shots      | portrait 4:5 | `product-*`                               |
| Cards and gallery  | portrait 4:5 | everything else                           |

JPG/PNG/WebP all work — update the extension in `src/data/site.js` to match.
To regenerate the placeholder set instead, run `node scripts/generate-images.mjs`.

## Notes

- Display and body type come from Google Fonts (Fraunces + Inter) with system
  fallbacks, so the site still renders correctly if the request is blocked.
- The contact form and the "Order this" button open the visitor's mail client.
  Point them at a real endpoint when you have one — see `onSubmit` in
  `src/pages/Contact.jsx`.
- `public/_redirects` makes client-side routing work on Netlify. On other
  static hosts, add the equivalent SPA rewrite to `index.html`.
